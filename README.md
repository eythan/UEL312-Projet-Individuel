## cvtic-solo

Bonjour,

J'ai fait les trois exercices (FibonacciSequence, Defer et BitArray), avec les questions bonus.

J'ai aussi écrit les tests unitaires avec PHPUnit pour vérifier les exemples de l'énoncé.

### installer les dépendances
```sh
./scripts/composer install
```

### lancer les tests unitaires
```sh
./vendor/bin/phpunit tests
```

### voir le résultat
Le fichier _index.php_ affiche un exemple pour chaque exercice :
```sh
php -S localhost:8000
